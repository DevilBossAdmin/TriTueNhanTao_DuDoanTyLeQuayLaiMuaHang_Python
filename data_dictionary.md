# Data Dictionary

| Feature | Type | Meaning |
|---|---|---|
| customer_id | string | Mã khách hàng |
| age | integer | Tuổi |
| gender | categorical | Giới tính |
| purchase_count | integer | Số lần mua |
| total_spent | float | Tổng chi tiêu |
| avg_order_value | float | Giá trị đơn hàng trung bình |
| days_since_last_purchase | integer | Số ngày từ lần mua gần nhất |
| website_visits_30d | integer | Lượt truy cập website trong 30 ngày |
| cart_adds_30d | integer | Số lần thêm sản phẩm vào giỏ trong 30 ngày |
| discount_usage_rate | float | Tỷ lệ đơn dùng mã giảm giá, 0-1 |
| support_tickets_90d | integer | Số ticket hỗ trợ 90 ngày |
| customer_tenure_days | integer | Thời gian khách hàng tồn tại |
| preferred_channel | categorical | Kênh mua/chạm chính |
| region | categorical | Khu vực |
| returned_90d | binary | Nhãn: 1 = quay lại trong 90 ngày, 0 = không |
